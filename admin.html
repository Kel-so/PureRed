💰 Valores dos Serviços

Esses valores alimentam a página Valores e o quiz Projetos Especiais, em português (R$) e inglês (US$). Depois de ajustar, baixe o pricing.json e substitua na pasta do projeto, igual ao projects.json.

Como publicar as alterações

Modo direto (recomendado): configure uma vez o token do GitHub no botão ⚙ lá em cima. Depois, é só clicar em 🚀 Publicar no site quando houver alterações — o painel envia os arquivos direto para o GitHub e o site atualiza em ~1 minuto.

Modo manual (sem token): baixe o arquivo alterado (⬇ projects.json / ⬇ pricing.json), substitua na pasta do projeto e envie: git add -A && git commit -m "atualiza portfolio" && git push

Dica: para adicionar um banner (imagem), coloque o arquivo em assets/banners/full/ e use esse caminho no campo "URL da imagem".

⚙ Publicação Direta

Com um token do GitHub salvo neste navegador, o botão "🚀 Publicar no site" envia o projects.json e o pricing.json direto para o repositório — sem baixar e substituir arquivo. Como criar (uma vez só):

  1. No GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Em Repository access, escolha "Only select repositories" e selecione Kel-so/PureRed
  3. Em Permissions → Repository permissions → Contents, marque Read and write
  4. Gere, copie o token e cole abaixo
