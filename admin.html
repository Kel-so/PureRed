🚀 Como publicar suas alterações no GitHub Pages?

Como o seu site roda estático de graça no GitHub Pages, você não tem um banco de dados hospedado em nuvem. Nosso sistema resolve isso de forma genial:

  1. Use o painel acima para Adicionar, Editar ou Excluir seus vídeos. Suas edições salvam instantaneamente localmente!
  2. Quando terminar todas as alterações, clique no botão "Exportar Banco de Dados (JSON)" ao lado para baixar seu arquivo projects.json.
  3. Substitua o arquivo projects.json existente na pasta do seu projeto por este que você acabou de baixar.
  4. Abra o terminal na pasta do projeto e rode: 
    git add projects.json
git commit -m "atualizacao de portfolio de videos"
git push
  5. Pronto! Em segundos o seu site público estará atualizado com os novos vídeos e alterações!
